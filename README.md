# 🌸 ركن رزان

تطبيق تعلّم منزلي: الحروف العربية ← القراءة ← القرآن، وقليل من الإنجليزية. الأم تجلس مع رزان وتحكم على القراءة.

- **التطبيق:** `index.html` — **صفحة المتابعة:** `parent.html?code=...`
- صفحات ثابتة على GitHub Pages، والتقدّم يُحفظ في قاعدة Convex (`convex/`) ويُدمج بين الأجهزة.

## تعديل المحتوى (بلا لمس الكود)
| الملف | المحتوى |
|---|---|
| `letters.js` | وحدات الحروف، الكلمة المفتاحية، الإيموجي، كلمات المواضع |
| `lessons.js` | دروس الحركات والسكون والمدود و«ال» والتنوين والشدّة + الكلمات البصرية |
| `stories.js` | القصص المفكوكة — كل قصة تُفتح بعد الدروس في `needs` |
| `quran.js` | يُولَّد من `scripts/gen_quran.mjs` |
| `english.js` | حروف phonics وكلمات CVC |

لا تغيّر `id` لأي درس أو قصة بعد النشر — التقدّم محفوظ عليه.

## الاختبارات
```
npm install && npm test
```
مهمة كاملة، ثم مهمة اليوم التالي (رجوع المتعثّرات ومعايير الإتقان)، ثم إتقان درس، ثم أرشفة السورة، ثم الدمج بين جهازين.

## الخادم
ملفات `convex/` مرجع فقط؛ النسخة الفعلية منشورة على Convex (مشروع Macaly). رمز الكتابة في `sync-config.js`، ورمز وليّ الأمر في متغيرات Convex فقط.
